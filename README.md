# Cafe Sales Dashboard

## Overview
This project presents an interactive Excel dashboard built to analyze cafe sales performance and turn transactional data into clear, management-facing insights.

## Objective
To track key sales KPIs and identify trends across products, branches, payment methods, dates, and hours of the day.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Summary Cards

## Dashboard Features
- Total revenue
- Total transactions
- Average revenue per transaction
- Total units sold
- Revenue over time
- Revenue by hour
- Revenue by branch
- Top-selling products
- Interactive filters for date, category, payment method, and branch

## What I Did
- Organized transactional sales data into a dashboard-ready structure
- Built KPI summary metrics to monitor overall sales performance
- Created interactive charts and slicers to make trend analysis easier
- Designed the dashboard to support quick business review and decision-making
